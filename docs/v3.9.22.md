3. 临时目录删除仍需确认：`cd ~/workspace/tasks/<id> && rm -rf src && … && cd src` 和 `rm -rf /tmp/cub5 && … SDK=$(…)` 各弹一次。
4. 确认卡片标题读不懂：「运行 \necho 并运行 \ncurl」「运行 for 并运行 do」「运行 python3 并运行 p」。
5. 被停止时没有任何 commit，前 4 项的成果只在 VM 工作目录里（提示词要求完成后才 commit）。

## 修复
- 计划项停滞检查（所有带计划的任务）：同一个计划项 40 步没勾（AIW_RABBIT_STEPS），先提醒模型退一步：是不是在调试环境；如果是，就记入「已知问题」，换一种验证方法或跳到下一项，需要决定时用 ask_user 给选项。80 步仍未勾，弹卡住卡片（含「继续执行（没卡住）」）。设为 0 关闭。
- 确认分类：解析同一行命令里的变量（`P=...`），识别 `localhost:端口` 和 `IP:端口` 地址；本机和内网地址只算中风险，不弹窗。
- 删除判定：只检查 rm 自己的目标里有没有 `$(…)`；在 ~/workspace 里 cd 之后的相对 cd（如 `cd src`）仍视为工作区内。
- 卡片标题：合并反斜杠续行；heredoc 内容不再当命令解析（`python3 - <<EOF` 会分析里面的 Python，危险操作照样要确认）；跳过 for/do/then/[ ] 这类关键字。
- iOS：补充要求、修改任务、ask_user 回答框改用 IMEField（UITextView）。任务运行时页面不断刷新，SwiftUI 的 TextField 会丢掉正在输入的拼音，所以首字母被截断。用 `scripts/v3922_ios_ime.py` 按字符串替换，不覆盖你本地的其他改动。
