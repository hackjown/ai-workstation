# 复刻视频（video-remake）

目标：用户给一条参考视频（上传的文件或链接），你交付一份可以直接拿去生成「同款视频」的材料：

1. 图片槽位表：@图片N → ID（人物A / 场景1）→ 要准备的参考图 → 生成提示词；
2. 人物生成提示词（每个出场人物一份，用来生成一致的参考图）；
3. 场景生成提示词（每个地点一份，无人物）；
4. 最终视频提示词：严格按用户的清理格式，每秒都用 @图片N 引用绑定的人物和场景。

本文件夹：`template.md`（交付模板，照着填）、`checklist.md`（清理规范 + 检查清单）、
`example-麻将局.md`（用户亲手整理的成品改写成的完整示例，格式以它为准）、`remake.py`（抽帧、校验、转 JSON）。

先读 `template.md` 和 `example-麻将局.md`，再开始。

## 第 0 步 · 拿到视频

- 上传的文件在 `~/workspace/uploads/` 下。链接：先 `yt-dlp -o ~/workspace/uploads/%(id)s.%(ext)s <url>`（没有就
  `pip install --user yt-dlp`）；抖音/小红书等下载失败时用 ask_user 请用户直接上传文件，不要猜内容。
- 名字 `<名>` 用视频文件名（不含扩展名）。所有产物放 `~/workspace/remake/<名>/`。

## 第 A 步 · 分析（抽帧 → 看帧 → 逐镜记录）

```bash
python3 ~/.claude/skills/video-remake/remake.py frames ~/workspace/uploads/<文件> --out ~/workspace/remake/<名>
```

它会：ffprobe 读分辨率/画幅/fps/时长/有无声音；按 ffmpeg 场景分数找硬切（单帧尖峰），另列「可能的切点」；
每秒中点抽 1 帧（`s001_000.50.jpg`），每个切点后抽 1 帧（`cut02_006.15.jpg`），拼一张带时间码的总览 `sheet.jpg`；
写 `analysis.json`。打印出来的帧路径已经是相对 `~/workspace` 的，直接给 read_image 用
（task-51d 把帧抽到 `uploads/frames2/` 却按 `uploads/f_001.jpg` 去读，浪费了一步）。

然后看帧：
1. 先 `read_image path=remake/<名>/sheet.jpg`：看全片节奏、人物数量、地点数量、切点是否准确（可能的切点逐个对照前后两秒的帧确认）。
2. 再按镜头分批 `read_image paths=[...]`（每批 ≤ 8 张，并行读），固定问题：
   「逐张描述：景别、机位角度、镜头运动（与上一张比）、每个人物的位置/动作/表情/视线、服装发型（颜色+材质+款式）、
   道具、光线方向与色调、画面文字。不要猜看不清的东西，看不清就说看不清。」
3. 外观拿不准（比如「抹胸裙还是连体短裤」）就对那一帧再问一次放大的问题，定死一种，不要在提示词里写「A/B」。
4. 有声音时：画面上有字幕就逐字记下台词及出现的秒数；没有字幕、听不到内容就在全片统一设定写「声音：按原片配乐，无对白」
   并在 done 里说明台词没法从画面确认。

记录到 `remake/<名>/分析.md`：每秒一行（秒、景别、机位、运镜、人物动作、光线），每个人物的外观定稿，每个地点的陈设清单。

## 第 B 步 · 人物生成提示词

- 每个能认出的、重复出现的人物一个槽位（主角、配角）；同框的一群背景人物用一个「群像」槽位。只露手或背影一闪而过的人不进槽位，镜头里写清服装颜色材质即可。
- ID：人物A、人物B…（用户自己起了名字就用用户的，例如 男A、女A）；群像1…
- 提示词写法见 `template.md` 第三节：外观、服装、发型、年龄段、中性站姿、正面+四分之三侧面、纯浅灰背景、均匀棚拍光。
- 只在部分秒数出现的道具（香烟、酒杯）不进参考图，否则视频模型会让它全程都在。

## 第 C 步 · 场景生成提示词

- 每个地点一个槽位，ID 场景1、场景2…，编号排在人物/群像之后。
- 画面里没有任何人；机位与视频主机位一致；画幅与原视频一致；道具逐个列出；光源写位置和色温。

## 第 D 步 · 最终视频提示词

严格照 `example-麻将局.md` 第五节的格式和 `checklist.md` 的规范：
参考图绑定 → 参考图使用规则 → 全片统一设定（含「时长与画幅：N 秒，<画幅>」）→ 逐秒提示词 → 输出约束。

- 逐秒：`第 N 秒（0:0N-1–0:0N）· 标题`，每秒一段，按「景别机位 → 场景@图片N → 构图占比 → 逐个人物动作表情视线 → 背景 → 光线色调景深 → 本秒限制」的顺序。
- 硬切那秒标题写「切：…」；同机位延续写「构图同上」「同机位」。
- 时长 > 15 秒：拆成片段（片段1 0–15 秒、片段2 …），每段一份完整的五段式提示词，各自从 0:00 计时，槽位表共用。

## 校验与交付

```bash
cd ~/workspace/remake/<名>
python3 ~/.claude/skills/video-remake/remake.py check 复刻_<名>.md --duration <秒>      # 有 ERROR 就改到 OK
python3 ~/.claude/skills/video-remake/remake.py json 复刻_<名>.md --duration <秒> --analysis analysis.json > 复刻_<名>.json
```

交付文档按 `template.md`：一、视频信息；二、图片槽位表；三、人物生成提示词；四、场景生成提示词；五、最终视频提示词（放在 ```text 代码块里方便复制）；附：逐镜分析。
send_file 两个文件（.md 和 .json），done 的总结写：时长与镜头数、槽位表（@图片N → ID → 要准备什么图）、check 结果、还拿不准的地方。

可选：用户要求「顺便生成参考图」时，才为每个槽位出图（有 image_edit 时：先用 python 生成一张 1024×1024 纯浅灰 PNG，再用 image_edit 把对应的生成提示词作为 prompt 画上去，保存为 `remake/<名>/图片N_<ID>.png`，read_image 检查后 send_file）。默认只交付提示词。
