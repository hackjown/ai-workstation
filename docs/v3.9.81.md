# v3.9.81 主聊天指挥引擎

| 你在主聊天说 | 去哪 |
|---|---|
| 让 agy 查一下天气的代码 / 让 agy 把 ldok 增加导出功能 | agy 的单聊（没说“新建任务”“继续”的都进单聊） |
| 让 agy 新建任务，做一个天气小程序 | 新任务（引擎页 › 任务） |
| 让 agy 继续 ldok，增加导出功能 / 继续完成 ldok 的任务 | 已有的 ldok 任务（标题或文件夹名对上；几个都像时会问你） |
| 让 codex 和 claude 一起做 ldok | 群聊任务 |
| 把 agy 默认模型设成 3.8 flash / codex 强度调高 / agy 现在用什么模型 | 引擎默认设置（engine_config） |
| agy 在干嘛 / 任务进度 | engine_status |

- 快捷解析（parse_dispatch）多了 mode：只有“新建任务/开个任务”是 new，“继续/接着/完成…任务”是 continue，其余都是 chat（单聊）。
- 默认模型：对话和任务没单独选模型时，每一轮都用引擎当前的默认模型（Bots.effective），改了默认马上对单聊和所有任务生效；单独选过模型的任务不变。
- engine_task 工具：mode、find（接着做的任务关键词）；dm 仍兼容（等于 mode=chat）。
- engine_config 工具：engine、model（照说法填，自动匹配模型列表的 id 或名字）、effort、workdir；什么都不填是查看。
- 单聊的回复只在那一轮是从主聊天发的（消息 data.via = chat）时才回到主聊天；在引擎页自己聊的不打扰主聊天。

测试：tests/test_v3981_chat_routes.py（4 个）。
