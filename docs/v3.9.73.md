# v3.9.73 引擎对话可以选电脑（3.9.73 build 47）

- 新建引擎对话（网页和 iOS）多了一个「电脑」选项，默认是「自动（按任务选）」，也可以直接选某一台电脑。
- 自动：第一条消息（连同标题、工作文件夹）决定在哪台电脑上做，之后就固定在那台。
  画 CAD、出图交给角色是「设计制图」的云电脑，渲染、剪辑视频交给「视频音频」的云电脑；
  写代码和其他事一律留在本地电脑（用户 2026-11-22：只有写代码必须在本地 VM）。没有对应角色的云电脑时也留在本地。
- 选定后对话里会出一条「这件事在 云电脑 N · 视频音频 上做」，对话标题下也会显示是哪台电脑。
- 每一轮开始前，云电脑如果在休眠会先唤醒；唤醒失败会在对话里写明原因。
- 云电脑上需要先装好引擎并登录（例如 agy 要装好并登录 Google 账号）；没装时提示会写明是哪台电脑。
- 选了不存在的电脑会直接报错「没有这台电脑」。
