# v3.9.49 联网工具：DeepSeek 搜索 / 读页 / 文档问答

基于 v3.9.48（6329514）。目的：查资料、读文章、做总结这类任务不再开虚拟机屏幕、不再一步一截图，改用 DeepSeek 的搜索和读页接口在 API 主机上完成；要登录、点击、下单或读不到正文时，自动回到桌面浏览器。

不配置 DeepSeek Key 时，一切和 v3.9.48 完全一样。

---

## 1. 接口（官方文档 2026-11-15）

| 工具 | 调用 | 说明 |
|---|---|---|
| `web_search` | `POST https://api.deepseek.com/v1/tools/search` | `query` 1–128 字（超长自动截断），`count` 1–50（默认 8），可带 `ori_question`（用户原话）、`need_content`。支持 `site:`、`-site:`、`"精确词"`、`lang:zh,en`、`after:`、`before:` |
| `web_fetch` | `POST https://api.deepseek.com/v1/tools/fetch` | 返回 `{title, content}`（Markdown）。网址带用户名密码的不发 |
| `doc_ask` | `POST /files` → `POST /chat/completions` → `DELETE /files/{id}` | PDF/Word/PPT 用 `text_recognition`（按页计费），txt/md/csv/xlsx/epub 等用 `user_data`（免费）。`purpose` 在 `file` 前面（否则 400）。`expires_after` = 1 小时（API 允许的最短），回答完立刻删除；删失败也会一小时后过期。模型 `deepseek-flash`，关闭思考 |

- 认证：`Authorization: Bearer <DeepSeek API Key>`。
- 出错：408 / 429 / 5xx 和网络错误自动重试 1 次；402 = 余额不足；401 = Key 无效；其它 4xx 不重试。
- 价格：搜索、读页各 $0.75 / 千次成功请求（搜索结果为空、读页没内容、失败、超时都不计费）；文档解析 $0.225 / 千页；`deepseek-flash` 输入 $0.30、输出 $1.20 / 百万 token（高峰价，估算偏高）。
- 限流：搜索 100 QPS、读页 25 QPS（账号级），读页另有按域名的限流。

## 2. Key 从哪来（按顺序取第一个有 Key 的）

1. 设置 › 联网工具 里指定的供应商（停用了就跳过）
2. 地址是 `api.deepseek.com` 的供应商
3. 「默认」供应商——**只在它的网关地址就是 api.deepseek.com 时**。默认网关是 OpenAI 或别家的话，那把 Key 不会发给 DeepSeek
4. 环境变量 `DEEPSEEK_API_KEY`

调用走该供应商的「代理」设置。

**第三方中转（自定义供应商）**：在 设置 › 联网 › 供应商 里明确选了一个地址不是 api.deepseek.com 的供应商（比如自建的 OpenAI 兼容中转）时，请求发到**它自己的地址**：`{地址}/tools/search`、`{地址}/tools/fetch`、`{地址}/files`、`{地址}/chat/completions`（地址里已含 /v1），用它自己的 Key；这把 Key 不会发给 api.deepseek.com。「自动」永远不会选第三方。中转只转发了聊天模型时，测试会显示「第三方「名字」不支持 /tools/search 接口」。文档模型可在「文档模型」里填中转那边的名字（留空 = deepseek-flash）。自定义供应商在 设置 › 模型 › 供应商 › 添加（联网卡片的「添加自定义」按钮打开同一个表单）。接口返回里永远不带 Key，只说 Key 来自哪里。

## 3. 读不到正文时

`web_fetch` 拿到的是下面这些就返回 `FAILED: …改用 browser_open 在桌面浏览器里打开`：

- 登录页（请登录、扫码登录、Sign in to continue… 且正文短）
- 验证 / 风控页（验证码、滑块、拼图、访问频繁、Just a moment、captcha…）
- 正文太短（默认少于 200 字，`AIW_DSWEB_MIN_CHARS`）
- DeepSeek 返回 403（安全策略拒绝）/ 404（没有可用正文）

正常文章页脚里有「登录 / 注册」链接不会误判（正文够长就放行）。

## 4. 任务路由（loop.py `web_lite()`）

只看用户自己的话（续做时只看「用户补充」那句）：

- 要有「查 / 搜 / 找一下 / 了解 / 读 / 总结 / 摘要 / 汇总 / 对比 / 新闻 / 最新 / 价格 / 是什么 / 介绍 / 翻译 / 报告…」或英文 search / look up / research / summarize / news / compare / find。
- 不能有：登录、注册、下单、购买、支付、预订、抢购、签到、点击、拖动、滑块、截图、填写、提交、发布、评论、上传、安装、打开某 App、微信 / 小红书 / 抖音 / 淘宝 / 京东 / 拼多多 / 美团 / 闲鱼 / B 站、桌面、屏幕、浏览器、画图 / CAD / PS / 修图 / 视频 / 剪辑、发邮件、写代码 / 部署…
- 带了非调研类技能（【技能：cad-drawing】这种）、视频或图片任务，都不算。

命中且 DeepSeek 工具可用时：

- 任务开头不截图、不调视觉模型（`_desktop_free`），时间线显示「联网：DeepSeek（不开浏览器）」。
- `web_search` / `web_fetch` / `doc_ask` 在 `_NO_SCREEN_TOOLS` 和 `_NON_GUI_TOOLS` 里：用它们不截图。
- 第一次用到 `browser_open` 或任何桌面工具时，时间线显示「联网：改用桌面浏览器（工具名）」，从下一步起照常截图。

没命中的任务也有这三个工具（规则写进了任务提示词：查资料先用它们），只是照常开屏幕。

## 5. 小秘聊天

- 有 Key 时多了 `web_search`（放在外部搜索连接器前面，状态「正在搜索…」）和 `doc_ask`（「正在读文档…」，超时 300 秒）。
- `read_url` 先走 Fetch API；DeepSeek 报错就照旧直接抓；读到登录 / 验证页时说明要交给电脑用浏览器打开。可在设置里关掉（聊天读网页）。

## 6. doc_ask 不发给 DeepSeek 的文件

- 照片 / 图片：jpg、png、heic、webp、gif、bmp、tiff、raw、dng、svg、psd…
- 压缩包 / 扫描包：zip、rar、7z、tar、gz…（扫描建模的 zip 也在这里）
- 模型和图纸：usdz、glb、gltf、obj、stl、ply、fbx、blend、dwg、dxf、step、3dm、skp、safetensors、ckpt、pt、onnx、gguf、bin…
- 文件名像证件或隐私材料：身份证、护照、户口、驾驶证、社保卡、银行卡、病历、体检、扫描件、银行流水、工资条、passport、id card…
- 其它不支持的类型

被拒时返回 `REFUSED: …`，不会发出任何请求。任务里只能问 API 主机上的文件（附件和任务交付的文件）；只在虚拟机里生成的文件要先 `send_file`。

## 7. 设置 › 联网工具

- 后端：DeepSeek（默认）/ 虚拟机浏览器（关掉全部三个工具，回到旧方式）
- 供应商：自动，或指定一个
- 文档解析、聊天读网页：开关
- 状态：是否启用、Key 来自哪里
- 用量：今天搜索 / 读页 / 文档次数、失败次数、费用估算；近 14 天合计
- 测试：搜 1 次 + 读 1 次（约 $0.0015），显示条数、字数和耗时

kv `web_tools` = `{backend, provider, doc_ask, chat_fetch}`。接口：`GET /api/web-tools?days=14`、`PUT /api/web-tools`、`POST /api/web-tools/test`（body 可带 `query` / `url`）。用量表 `web_tools_usage`（每次调用一行，带 task_id）。

## 8. 命令行（aiw_news.py）

```
docker exec aiw-api sh -c 'cd /app && PYTHONPATH=services/api python -m aiw_api.dsweb search "今天 AI 新闻" --count 10 --json'
docker exec aiw-api sh -c 'cd /app && PYTHONPATH=services/api python -m aiw_api.dsweb fetch https://example.com/a --json'
```

Key：容器里能读到数据库（`AIW_DB`，默认 `workspace/aiw.db`）和旁边的 `.secret_key`（或 `AIW_SECRET_KEY`）时用设置里的 Key，否则用 `DEEPSEEK_API_KEY`。命令行从不新建 key 文件。退出码：0 成功，2 出错，3 读到登录 / 验证页。

## 9. 对比 VM 路径和 DeepSeek 路径

```
docker exec aiw-api python scripts/web_compare.py --n 10
docker exec -e AIW_API_TOKEN=你的token aiw-api python scripts/web_compare.py --n 10 --rerun
```

第一条只读：列出最近 10 个会走 DeepSeek 的已完成任务和旧跑法的状态、分钟、步数、截图数、浏览器步数、token。第二条把它们作为新任务在 DeepSeek 路径上逐个重跑（同一台电脑，每个最多 900 秒），并排对比，报告存到宿主机 `./data/web-compare-<时间>.md / .json`。重跑是真任务，只会挑「查 / 读 / 总结」类；结果质量要人工看一遍。
