# v3.9.62 引擎：表单排版、按引擎读取模型

## 修复
- 引擎的表单（新对话、新群聊、交给管家、模型和强度）改回 AIW 的表单样式：标题 + 每项「名称在上、输入框在下」，说明文字放在输入框下方。之前用的 `.col` 样式不存在，字段挤在一起。
- 新对话里换引擎，模型列表立刻换成「读取 CodeBuddy 的模型…」，读到后显示该引擎自己的模型；不会再停留在 agy 的列表上。「默认」写的是当前引擎名。
- 模型列表最后多一项「其他（手动填模型名）」，列表里没有的模型可以直接填。
- 引擎没有强度选项时（Claude Code、CodeBuddy）隐藏「强度」。

## 各引擎的模型从哪来
- Codex：`codex debug models`（这个登录能用的模型目录，不调用模型），读不到就用 `~/.codex/models_cache.json`，再不行用内置目录；每个模型带自己支持的强度。
- Grok Build：`grok models`，加上 `~/.grok/config.toml` 里配的模型（包括第三方中转）。
- CodeBuddy：没有列出模型的命令（`codebuddy models` 会当成一句话开聊，以前会卡住几十秒），改为读 `~/.codebuddy/settings.json` 里的模型，其余手动填。
- Claude Code：opus / sonnet / haiku。
- Antigravity：不变（`agy models`）。
