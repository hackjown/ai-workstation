# v3.9.72 适配 agy 1.5.14（3.9.72 build 46）

agy 的变化（官方 changelog）
- 1.5.0（2026-11-04）：headless 运行不再在隐藏的 30 分钟后停掉后台任务，而是等它跑完。
- 1.5.7：没设 agentMode 时默认 auto 模式（安全命令自动跑，风险操作仍要批准）。
- 1.5.14（2026-11-21）：auto 模式读工作区外的文件不用再确认；写仍要批准。

AIW 的适配
- agy 在等后台任务时没有输出，AIW 原来 20 分钟没输出就判定卡住并中断这一轮。现在每 30 秒看一次 agy 子进程的 CPU，
  子进程还在干活（30 秒内用了 1 秒以上 CPU）就不算卡住。用 setsid 脱离出去的任务不算 agy 的子进程，那种情况这一轮会先结束、之后看日志。
- check 返回 outdated / min_version（低于 1.5.14 时 outdated=true）。
- v3.9.71 的默认规则（后台脚本、读技能/npx）保留，旧版 agy 也能用。

升级（在 VM 上用 aiw 账号）：agy update，然后 agy --version 应显示 1.5.14 或更高。
