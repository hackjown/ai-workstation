# 复刻视频 · 清理规范与交付检查清单

交付前逐条过一遍；`python3 ~/.claude/skills/video-remake/remake.py check <交付.md> --duration <秒>` 会自动查带 ★ 的条目。

## 结构
- ★ 最终视频提示词按顺序五段：参考图绑定 → 参考图使用规则 → 全片统一设定 → 逐秒提示词 → 输出约束。纯文本，不用表格，不加「通用前缀」。
- ★ 绑定行格式：`@图片N是<ID>（<服装+发型+标志特征>）`，从 @图片1 起连续编号；人物/群像在前，场景在后。
- ★ 交付文档里每个槽位都有：槽位表一行（第一列就是 @图片N）+ 一个 `### @图片N · <ID>` 生成提示词小节。

## 绑定与命名
- ★ 每个被引用的 @图片N 都已绑定；每个绑定的槽位至少在一个镜头里出现。
- ★ 镜头里人物只写 @图片N，不写别名（男A、人物A）也不写泛称（男子、女主）。只露手、背影且不进槽位的人，写清服装颜色和材质（例：一双女性的手（米黄长袖衬衫、袖口卷起））。
- ★ 绑定描述定死一种外观，不写「A/B」「A 或 B」。
- 一个槽位一个人；同框的多名背景人物用一个群像槽位，并在使用规则里写「每人取其中一位，不得重复使用同一人」。
- 场景槽位只参考空间、陈设、材质、色调；场景参考图里没有人。
- 只在部分秒数出现的道具（香烟、酒杯、武器）不进人物参考图，也不写进绑定描述，改在镜头和输出约束里限定秒数。

## 时间
- ★ 标题格式 `第 N 秒（0:0N-1–0:0N）· <镜头标题>`（短横为 en dash「–」）；跨多秒写 `第 3–4 秒（0:02–0:04）`。
- ★ 从 0:00 开始，前后衔接，无空档无重叠，最后一镜结束 = 视频时长。
- ★ 时长写在全片统一设定「时长与画幅：N 秒，<画幅>」。超过 15 秒拆成多个片段，每段单独一份完整提示词、各自从 0:00 计时。
- 硬切发生的那一秒标题写「切：…」，同一镜头的后续秒用「同机位」「构图同上」。

## 每秒内容（按这个顺序写）
1. 景别 + 机位角度（远景/全景/中景/中近景/近景/特写/极近特写；平视/略仰/俯拍）。★ 每秒至少有景别或运镜。
2. 场景槽位（新镜头第一秒写「场景@图片N」）。
3. 构图：谁在左/中/右，画面占比用「约 60%」这样的数。
4. 每个出场人物的动作、表情、视线，逐人写；不动的写「其余静止」。
5. 背景人物状态（「背景@图片4虚化但仍可见」）。
6. 光线落点 + 色调 + 景深。
7. 本秒限制：「不得…」（不得提前码牌、不得移出画框、嘴上无烟）。

## 用词
- ★ 不用含糊词：等等、之类、若干、大概、也许、或许、一些、某种、尽量、随意、自行发挥；列举不用「等」收尾，要列全。
- ★ 不用空泛修饰：高清、4K、电影级、大师级、唯美、AI生成。用具体的光线、色温、颗粒、景深代替。
- 数字具体：色温约 3200K、占比约 60%、香烟仅第 1–2 秒。
- 前后同一个东西用同一个词（麻将桌就一直叫「深色麻将桌」）。

## 输出约束（最后一段必须有）
- ★ 每个人物槽位锁服装：「@图片1米白西装……全程不得变装」。
- 面部一致：「面部特征与参考图一致，不得崩坏、不得互串」。
- 限时道具的秒数窗口。
- 背景人物：不得与主角撞脸，虚化但可见/不得全黑。
- ★ 全程无文字、无字幕、无水印（除非原片有必须保留的文字，那就逐字写出内容和位置）。

## 人物/场景生成提示词
- 人物：性别、年龄段（如 25–30 岁）、肤色、脸型五官、发型发色、妆容、上装/下装/鞋（颜色+材质+款式）、配饰、标志特征；全身中性站姿、表情平静、正面+四分之三侧面并排、纯浅灰背景、均匀棚拍光、写实摄影。附负面。
- 群像：N 人并排不重叠，1号/2号… 每人一套造型；负面里写「与主角相似的面孔」。
- 场景：时代风格+空间类型、主体陈设及位置、材质、逐个列出的道具、光源位置与色温、氛围、与视频主机位一致的机位、画幅、「画面中没有任何人物、没有手、没有文字」。

## 交付
- 文件：`remake/<名>/复刻_<名>.md` 和 `remake/<名>/复刻_<名>.json`（`remake.py json … --analysis remake/<名>/analysis.json`），两个都 send_file。
- done 的总结里写：时长、镜头数、槽位表（槽位 → ID → 要准备的图）、check 结果。
