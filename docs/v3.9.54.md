# v3.9.54（2026-11-19）

## 需求
把 Google Antigravity 接入 AIW，让 AIW 管理 Antigravity 的开发工作：AIW 派任务、看过程、验收、决定交付。

## 方案
Antigravity 有四个入口（2.0 桌面版、IDE、CLI、Python SDK）。桌面版和 IDE 没有程序接口；CLI 的无界面模式（`agy --input-format stream-json --output-format stream-json`）可以在一个进程里多轮对话，并逐步输出 init / step_update / result 事件，最适合被 AIW 驱动。本版只接 CLI。

```
AIW 任务（编码）
  └─ antigravity op=start  → 电脑上 agy_bridge.py：git worktree add -b aiw/<job>，后台守护进程启动 agy
     antigravity op=wait   → 阻塞到这一轮结束：工具步骤、agy 的报告、改动文件、被拒动作
     AIW 自己验收（shell 跑测试 / verify_html）
     antigravity op=send   → 把失败输出发回同一会话（同一进程，保留上下文）
     antigravity op=diff   → 审 diff；done 时告诉用户分支名
     antigravity op=stop   → 结束会话（worktree 和分支保留）
```

## 改动
- `agent_runtime/agy_bridge.py`（新，只用标准库）：在电脑上运行。`check [--probe]` / `start` / `wait` / `send` / `diff` / `stop` / `list`，以及常驻的 `daemon`（持有 agy 进程，事件写 `~/.config/aiw/agy/jobs/<job>/events.jsonl`，状态写 `state.json`，追加指令走 `inbox/`）。看门狗：本轮无输出超过 idle 分钟发 SIGINT（状态 stuck），总时长超时（timed_out），空闲会话保留 60 分钟后结束。stderr 里的权限拒绝记入 `denied`。
- `agent_runtime/antigravity.py`（新）：首次使用时把 bridge 写到电脑（sha1 相同则跳过）并在没有设置文件时写默认权限规则；拼 agy 的任务说明（任务 + 任务契约的验收项、源头、必须保留、允许修改的路径 + 规则：只在 worktree 里改、提交、不推送、先跑测试）；把结果整理成模型读的说明（明确要求 AIW 自己验收）。
- `tool_router/registry.py`：新工具 `antigravity`（loop 处理）。
- `agent_runtime/loop.py`：`_antigravity`；工具默认隐藏，按 `antigravity.offered()` 显示；不截屏；停止任务时一并 `stop` 这个任务启动的 agy 会话；`wait/send/diff/stop` 不写 job 时默认用本任务最近的 job。
- `aiw_api/lessons.py`：工具归入 shell 类。
- `tests/test_v3954_antigravity.py` + `tests/fixtures/fake_agy.py`：用模拟的 agy（同样的 stream-json 协议）测完整流程、多轮、权限拒绝、无输出看门狗、非 git 目录、开关、loop 端到端和停止。

## 配置
| 变量 | 默认 | 说明 |
|---|---|---|
| `AIW_AGY` | auto | 0 关闭；1 所有编码任务可用；auto 只在请求提到 Antigravity / agy / 反重力 时可用 |
| `AIW_AGY_MODEL` / `AIW_AGY_EFFORT` | 空 | agy 的模型 slug（`agy models` 查看）和推理强度 |
| `AIW_AGY_MODE` | accept-edits | 也可 plan（只写实施计划）、auto（需要沙箱，企业账号不可用） |
| `AIW_AGY_TIMEOUT_MIN` / `AIW_AGY_IDLE_MIN` / `AIW_AGY_MAX_TURNS` | 120 / 15 / 8 | 总时长、无输出超时、最多轮数 |
| `AIW_AGY_SANDBOX` | 0 | 1 = `--sandbox` |
| `AIW_AGY_REMOTE_CONTROL` | 0 | 1 = `--remote-control`，可在浏览器里看/接管 |
| `AIW_AGY_SKIP_PERMISSIONS` | 0 | 1 = `--dangerously-skip-permissions`，只在用完即毁的电脑上开 |
| `AIW_AGY_BIN` | agy | agy 路径（不在 PATH 时） |

## 电脑准备（一次）
1. 从 https://antigravity.google/download 安装 Antigravity CLI，确认 `agy --version`。
2. 在电脑终端运行一次 `agy` 登录 Google 账号；或在 settings.json 写 `"modelProvider": "gemini"` 并设置 `GEMINI_API_KEY`。
3. 国内电脑给 vm-agent 的环境加 `HTTPS_PROXY`。
4. 在 AIW 里说「用 antigravity 检查一下这台电脑」，模型会调用 `op=check probe=true`。

## 未验证
- 没有在装了真实 agy 的电脑上跑过：事件字段按官方 headless 文档（2026）实现，测试用的是模拟 agy。
- stderr 里权限拒绝提示的原文格式按关键词匹配（denied / permission / permissions.allow），实际措辞可能不同。
- 网页 / iOS 没有专门的 agy 卡片，步骤显示在普通工具结果里；设置页还没有开关，用环境变量配置。
