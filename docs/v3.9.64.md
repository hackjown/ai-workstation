# v3.9.64 聊天里查引擎对话、接着做

## 需求
在聊天里让 AIW 找到引擎里已有的对话（例如 agy 的「ldok后端对接」），再让 AIW 直接把这个任务做完。

## 改动
- `bots.py`：`Bots.find_convs(q, bot, limit)`，按标题、文件夹、消息内容搜（空格分开的词都要匹配，群聊成员也算），最新的在前，带匹配片段、最后一条、消息数、是否正在回复/管家接管。
- `chat.py`：新工具 `engine_convs`（query 搜索 / conv 读最近几轮）；`engine_task` 新增 `conv` 参数，`engines` 不再必填。
- `bot_groups.py`：`Dispatch.run` 支持 `conv`，在该对话里接着发；`manage` 时交给管家盯到做完。没有给文件夹时，任务里出现了该引擎已有对话的标题（至少 4 个字）就复用那个对话。
- 测试：`tests/test_v3964_engine_convs.py`。版本 3.9.64 (38)。

## 用法
- 「找一下 agy 里 ldok 后端对接的对话，看看做到哪了」
- 「让 AIW 盯着把它做完」/「在那个对话里接着把剩下的对接做完」

## 未验证
- 是否调用工具由聊天模型决定，没在真实模型上跑过；顶部搜索框（session_search）还不搜引擎对话。
