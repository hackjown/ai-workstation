# v3.9.53（2026-11-18）

## 问题
1. 2026-11-18 07:30 新闻早报：天气正常，「GitHub 新榜」没有数据。
2. 早报要增加专门的全球 AI 新闻。
3. 聊天里上传的图片、视频只显示文件名。

## 原因
- GitHub 新榜由 VM 上的 `aiw_news.py` 自己抓取，失败时页面只留空栏，API 侧没有兜底（脚本本身不在仓库里）。
- 用户消息的附件在网页（`home.js` `hMsg`）和 iOS（`UserBubbleV2`）都只渲染成文件名标签。

## 改动
- `aiw_api/brief_extras.py`（新）：AI 新闻源抓取、去重、小模型挑选并翻译；GitHub trending 解析 + 搜索 API 兜底；以 `<section id="aiw-ai-news">` / `<section id="aiw-trending">` 插入天气之后，各一次。
- `aiw_api/chat.py` `post_routine_result`：早报成功后调用 `brief_extras.enrich`（最多 150 秒）；没有 html 时把两栏文字放进聊天消息。
- `aiw_api/main.py` `/api/artifacts`：非下载的 `.mov` / `.m4v` 以 `video/mp4` 返回（Chrome 可播 H.264 QuickTime）。FileResponse 支持 Range。
- `apps/web/home.js` + `home.css`：`hAttPreview` —— 图片走 gallery + 灯箱，视频 `<video controls>`，其他文件保持标签。
- `apps/ios/Sources/AttachmentPreview.swift`（新）+ `HomeV2.swift`：图片缩略图、视频首帧 + 播放键，点开全屏（VideoPlayer）。
- `tests/test_v3953_brief_extras_previews.py`：8 个测试。

## 未验证
