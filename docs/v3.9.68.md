# v3.9.68 引擎权限请求变成聊天里的确认卡片

- agy 被权限拦下、需要你决定时（你自己在聊、或管家换过做法后还被拦），AIW 聊天里出一张「需要你确认」卡片，并推送通知（和任务的确认一样的提示音），点通知直接到这张卡片。
- 卡片写清：哪个引擎、哪个对话、想运行的命令、允许后会加的规则；三个按钮：
  - 允许这类命令：加上建议的窄规则（以后也算数），接着原会话做完；
  - 只这一轮全放开：这一轮不做权限检查（先再确认一次），下一轮恢复；
  - 拒绝：不放开、不重跑；管家在等时就停下交还给你。
- 「打开对话 ›」跳到那个引擎对话；引擎对话里那条回复下也有同样三个按钮（多了「拒绝」），在哪边点都行，另一边同步变成已处理。
- 一个对话只有一张待处理卡片：你在对话里接着发了别的话，或又被拦下出了新卡片，旧卡片显示「已过期」。
- 管家第一次被拦仍是自动换写脚本的做法，不出卡片。
- API：`POST /api/bots/convs/{id}/permit` 的 mode 新增 `deny`。聊天消息 kind `engine_permit`。
- 未验证：Swift 未编译。
