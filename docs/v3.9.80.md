# v3.9.80 引擎头像、单聊和配置

## 引擎页
- 顶部头像栏：每个可用引擎一个固定头像，用它自己的 logo 和颜色描边（不再用 AIW 的琥珀色圈）。右下角圆点：绿色空闲，琥珀色在干活，灰色云端引擎还没配置凭据。
- 点头像：打开这个引擎的单聊（bot_convs.kind = 'dm'，每个引擎一个，POST /api/bots/dm/{bot} 取或建）。单聊不能删，菜单里有「新话题」（POST /api/bots/convs/{id}/new_topic：停掉正在跑的进程、清掉 session，下一句开新会话，历史保留）。
- 点名字（网页）/ 长按头像（iOS）：配置（GET|PUT /api/bots/engines/{bot}/config，表 bot_engine_cfg）：模型、强度、电脑、单聊的工作文件夹；云端引擎在这里进「配置凭据」。新建任务没填模型、强度、电脑时用这里的默认值；改模型会同步到单聊。
- 「新建任务」：选一个引擎是单独任务；选几个是群聊任务（管家分工、本地引擎各开分支、做完合并）。列表分「群聊任务」和「任务」。
- GET /api/bots 的每个引擎多了 cfg、busy（正在跑的对话数）、dm（单聊 id）。

## 主聊天
- engine_status：所有引擎是否空闲、正在跑的对话、各群聊的状态、在等谁、还剩几步。
- engine_task 新参数 dm：true 时发到这个引擎的单聊里，带着单聊的上下文。

## 平台
- 网页（Android 用同一套网页）和 iOS（EngineView.swift：头像栏、单聊分组、EngineCfgSheet、新话题）。Swift 没在本地编译，靠 CI。
