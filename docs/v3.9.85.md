# v3.9.85

- AIW 刚帮你查过某个引擎任务（比如 agy 的「增加对115网盘的刮削」），接着你说「让 agy 按你的要求改代码」时，「交给 @agy」按钮会把话和方案发进**那个任务**接着做，而不是 agy 的单聊；用的是那个任务的文件夹，也就不会再撞到单聊文件夹的权限拦截。
- 查的是引擎单聊，就发回那个单聊里接着做。
- 「刚查过」指 3 小时内 AIW 打开过或搜到的那个任务；都没有的话发到单聊。
- Cue 生成的图片、视频、音频和文件：官方 API 返回的临时下载链接，AIW 在这一轮结束时复制到本机，直接显示在引擎对话里（图片直接看，视频/音频可播放，其他文件可下载）；回复正文里指向 Cue 沙箱路径的图片链接会去掉，避免出现坏图。
- 网页端电脑画面加了「全屏」按钮（右侧电脑栏和 电脑 页面都有），按 Esc 或再点一次退出；只在观看时点全屏会先自动接管。
- Meta Muse 的图片/视频没有改。
