# v3.9.63 CodeBuddy 模型和强度、引擎颜色

## 问题
v3.9.62 里选 CodeBuddy 时模型下拉只有「默认」和「其他」，强度一栏不显示。

## 原因
- CodeBuddy Code 没有非交互的模型列表命令，列表只在交互界面 `/model` 里按账号显示。v3.9.62 只读 `~/.codebuddy/settings.json` 的 `model`，没设置时就是空的。
- CodeBuddy 的强度表留成了空的，界面就把强度隐藏了。CodeBuddy 实际支持 settings 的 `reasoningEffort`（minimal、low、medium、high、xhigh、max）。

## 改动
- `cli_bridge.py`：CodeBuddy 模型 = settings.json 的 model + `~/.codebuddy/models.json`（models、availableModels）+ 静态列表（2026-11-21 WorkBuddy 账号 `/model` 显示的模型，标签带积分倍率）。
- CodeBuddy 强度六档；选了强度时命令加 `--settings '{"reasoningEffort":"<档位>"}'`，不选则用 CodeBuddy 自己的默认。
- 引擎颜色：agy 紫红 #c026d3（原来和 CodeBuddy 的蓝几乎一样）、Codex 绿、Claude 橙、CodeBuddy 蓝、Grok 黑（深色模式浅灰）；用在头像、回复上的引擎名、对话列表当前项左侧色条。iOS 列表没有头像，未改。
- 版本 3.9.63 (37)。

## 未验证
- 静态列表来自一个账号的截图，别的账号可用模型可能不同；没有的模型 CodeBuddy 会报错，可改用「其他」手动填。
- `--settings` 传 reasoningEffort 依据官方文档，未在 VM 上实测。
