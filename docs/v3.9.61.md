# v3.9.61 引擎群聊；主聊天直接派活给引擎

## 引擎群聊
- 「引擎」页新增「新群聊」：选一个 git 仓库和几个引擎（codex / claude / codebuddy / grok / agy），每个引擎在自己的 git worktree 和分支 `aiw/<群id>/<引擎>` 里干活，互不干扰。
- AIW 管家拆分任务：你说一句需求，管家给每个引擎分一部分（拆不开时每个引擎做同一件事）；在群里 `@codex` 可以只发给某个引擎。
- 合并：全部完成后，管家把各分支合进 `aiw/<群id>/merge`（工作文件夹 `_merge`）。有冲突就交回给对应引擎解决，最多 2 次（`MAX_FIX=2`），仍不行就交给你决定。**不推送、不动原分支**。
- 群聊可停止、删除（删除不删分支和 worktree）。
- 接口：`GET/POST /api/bots/groups`，`GET/DELETE /api/bots/groups/{id}`，`POST …/send`、`…/merge`、`…/stop`。
- 新文件 `services/api/aiw_api/bot_groups.py`；`bot_convs` 新列 `grp`、`origin`、`branch`，群成员的单独对话不在对话列表里显示。

## 主聊天派活
- 在主聊天里说「让 codex 修一下登录」「让 claude 和 grok 一起做一个登录页」：一个引擎就开一个引擎对话，多个引擎就开一个群聊。结果带「打开引擎对话 / 打开群聊」按钮，引擎完成后结果回到聊天里。
- 主模型也可以调用新工具 `engine_task` 派活；状态显示「正在交给引擎…」。

## 网页 / iOS
- 网页：引擎侧栏多了群聊列表、新建群聊、群聊页面（成员分支状态、合并、停止、删除）；首页结果卡片可直接打开；深链 `bots?g=<群id>`。
- iOS：引擎右上角菜单「新对话 / 新群聊」，群聊列表和群聊页面（`EngineGroupView`）。

## 修复
- 多个引擎同时安装桥接时临时文件冲突：`cli_engines.py`、`antigravity.py` 改为写 `$f.$$.tmp` 再 `mv -f`。
- 「做一个登录页」不再被吞掉「做」字；派活时的路径识别更严格。
