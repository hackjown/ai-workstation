# v3.9.23 粘贴到 VM 多出字符、接管时看不到鼠标

## 粘贴前面多一串、结尾多一个 ~
原因：粘贴进终端时，终端会把内容包在 bracketed paste 标记 ESC[200~ … ESC[201~ 里。读取这一行的程序如果不认识这两个标记，就会把它们当成文字显示，看起来就是前面多出 [200~、结尾多出 ~。
修复（protocols/aiw_protocols/input_ops.py 的 paste_script，服务器端生效，不用更新 vm-agent）：
- 先看当前窗口的类名，判断是不是终端（gnome-terminal、xfce4-terminal、xterm、konsole、kitty、alacritty 等）。
- 终端里的单行文字（1500 字以内）改为用 xdotool 逐字输入，不经过粘贴，就不会带标记。结尾的换行会去掉，粘贴后不会自动执行。
- 多行或更长的文字仍然粘贴，并且固定用 Ctrl+Shift+V（在终端里 Ctrl+V 是「原样插入下一个字符」）。同时在 ~/.inputrc 写入 `set enable-bracketed-paste off`，新开的 bash 不再要求终端加标记。注意：关掉后，多行粘贴会逐行执行。
- 浏览器、文档等其他窗口不受影响。

## 接管时有时看不到鼠标
desktop_view.py：接管模式开启 noVNC 的 showDotCursor。VNC 服务器发来空光标或透明光标时，显示一个小圆点代替；连接后把键盘焦点交给画面。
XFCE 或 Xvnc 缺少光标主题时，部分窗口上光标也会消失。补装方法：在 VM 上执行 `sudo apt-get install -y dmz-cursor-theme adwaita-icon-theme && DISPLAY=:1 xsetroot -cursor_name left_ptr`。云电脑（InstaBox）使用对方的播放器，这项修改对它不生效。
