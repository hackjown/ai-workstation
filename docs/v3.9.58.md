# v3.9.58 引擎：附件、技能、模型和强度

## 改动
- 导航和页面标题「引擎对话」→「引擎」。
- 输入框：＋ 菜单（拍照 / 照片视频 / 文件 / 技能），`/` 技能选择器，技能标签、附件上传进度，与主聊天同一套上传（`POST /api/uploads/raw`，留在 API 主机）。
- 发送：`POST /api/bots/convs/{id}/send` 接受 `attachments`、`skills`。附件经 `files.upload` 复制到 `<工作文件夹>/uploads/`（工作文件夹不在 `~/workspace` 下时放 `~/workspace/uploads/`，桥接再按路径复制进文件夹）。技能用 `agent_runtime.skills.brief()` 写成说明；用户自定义技能读 `skills_custom`。
- 模型：`agy_bridge.py models`（v4）先跑 `agy models --output-format json`，失败再读文本输出，按 `-low/-medium/-high/-xhigh/-max` 后缀合成模型组。`bot_convs` 新列 `model`、`effort`、`job_model`。带强度后缀的 slug 不再传 `--effort`（agy 会报冲突）。模型变了，下一轮先停掉旧进程，再用 `--conversation <session>` 和新模型启动。
