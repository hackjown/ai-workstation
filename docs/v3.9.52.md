# v3.9.52（2026-11-17）

## 问题
1. 2026-11-17 07:30 新闻早报（task-ea696df118）：聊天里收到的是 `aiw-news-2026-11-17.zip`，不是 html；早报里没有天气。
2. task-22ddf5813d：相册里选的视频上传成 `photo-1794874653.jpg`（实为 MOV，720×1280，28.57 s），任务按照片处理。

## 原因
- send_file 发 html 三次被 v3.9.50 金额大写自检拒收：正则 `[零壹…拾佰仟万亿]+元` 把新闻里的「亿元」「万元」当成大写金额。拒收计数按文件名，模型改名、打 zip 绕过。
- 天气只拼在聊天消息文字里，早报 html 本身没有；Open-Meteo 在 API 主机上读不到时只有一行「暂时没读到」。
- iOS「+ › 照片」：选中的视频未报告为 movie 类型时，走照片分支，`UIImage(data:)` 失败后原样以 `photo-<ts>.jpg` 上传。服务器只看扩展名。

## 改动
- `agent_runtime/money_cn.py`：没有壹～玖大写数字的不算大写金额；拒收说明里禁止打包/改名绕过。
- `agent_runtime/loop.py`：金额拒收按任务计数（两次后放行并在时间线警告）。
- `aiw_api/brief_weather.py`：Open-Meteo 两次后改用 wttr.in；`to_html` / `inject_html` 把天气放进早报页面。
- `aiw_api/chat.py`：定时结果里只含一个 html 的 zip 改发 html；早报 html 顶部写入天气。
- `aiw_api/uploads.py` + `main.py`：`sniff` / `fix_kind` 按文件头纠正扩展名和类型。
- `apps/ios/Sources/HomeChat.swift`、`ChatView.swift`：`videoExt` 识别后按视频上传。iOS 要重新打包才生效；服务器端修复对所有客户端立即生效。
- `tests/test_v3952_brief_upload_fixes.py`：7 个测试。
