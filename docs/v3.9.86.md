# v3.9.86 引擎群聊：项目模式（讨论 → 设计 → 开发 → 评审 → 验收 → 实测截图 → 交付）

在有仓库的引擎群里，以「项目规划：」「项目：」「/项目」「开发项目」开头发一份规划，AIW 管家就按整条流程带大家做完：

1. **讨论**：每位成员（云端先说）给出意见，这一步不改文件。管家汇总写出**定稿方案**：功能清单、技术方案、目录结构、验收标准、分工、评审人、验收命令、启动方式。
2. **设计（有前端时）**：管家选 2～3 位成员各出一套设计方案。本地成员做自包含的静态设计稿 `design/<引擎>.html`，管家在电脑上用无头浏览器打开截图；Cue 直接出效果图。所有方案以图片发到群里，标「方案 A / B / C」，点「用方案 X」或回复“选 B”。没有前端时，看完定稿方案点「开工」。
3. **开发**：按分工一步一步做，每一步都带着定稿方案和选定的设计稿，后一步自动合入前一步的成果。
4. **评审 + 返工**：评审人对照定稿方案和设计稿评审；管家把必须修的问题交回给负责的成员，改完复审，最多 2 轮，还没解决的写进报告。
5. **验收 + 返修**：管家合并各分支、在合并后的代码上跑验收命令；失败时把输出交给对应成员修，修完再验收，最多 2 次。
6. **实测截图**：管家在合并后的代码上启动项目（定稿方案里的启动命令，固定高位端口），等页面能打开后逐页截图，再停掉进程；命令行工具则运行演示命令，把输出排成终端样式截图。截图附在验收报告里。
7. **交付**：报告下面三个按钮：「生成补丁」（补丁文件直接在群里下载）、「推送分支」（push `aiw/<群>/merge`）、「合入 <基线>」（只在你的仓库正停在基线分支且没有未提交改动时才合）。不点就什么都不推送、不合并。

群顶部有阶段条，显示现在在哪一步、选了哪个方案、返工几轮、交付了什么。随时可以「停止」；停在某一步时说「@管家 继续」接着做。

需要：电脑上装有 chromium（或 google-chrome，或 Python playwright）才能截图；没有时报告里会写明。
iOS 端的群聊暂未显示阶段条和按钮（可以回复文字“开工”“选 B”“生成补丁”代替）；Android 用网页版，已支持。
