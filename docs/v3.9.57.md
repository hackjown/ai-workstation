# v3.9.57 引擎对话（Bot）与引用

## 是什么
- 引擎对话 = 电脑上一个编程 Agent CLI 的原生会话。第一期：Antigravity（`agy`）；Codex 下一期（`codex exec --json` / `codex exec resume`）。
- 三种发言者：你（user）、AIW 管家（aiw）、引擎（bot）。系统提示（system）记录接管开始/结束。

## 运行方式
- `agy_bridge.py` 新增 plain 模式（bridge v3）：`job.plain=true` 时不建 worktree，`workdir` 就是工作区（不存在就建），`changes` 显示 `git status --short`（不是仓库就不显示）。
- 每轮：会话进程还在就 `send`，否则 `start`（带上次的 `conversation_id` 续上）。之后每 20 秒 `wait` 一次，把步骤实时写进回复卡片。
- 进程空闲 120 分钟退出；单会话最长 24 小时；轮数上限 1000。
- 权限规则沿用 v3.9.56（只认 read_file / write_file / command；push、reset、改 ~/.gemini 等仍被拒）。

## 管家接管
- `POST /api/bots/convs/{id}/takeover {goal, rounds}`：没有回复可判断时，管家先把目标发过去；之后每轮用聊天模型判断 `{done, next, report, ask_user}`。
- 停下的条件：done、ask_user（push、花钱、删数据、意图不明都必须问你）、轮数用完、模型出错。停下时推送通知。
- 你插话：先发你的话，接管继续。「收回」立刻结束接管；「停止」同时结束 agy 当前这一轮。

## 引用
- `POST /api/chat/send {quote}`、`POST /api/bots/convs/{id}/send {quote}`：quote 是消息 id（主聊天或引擎对话都行）。
- 服务器带上被引用那条（≤1500 字）和它前两条、后一条（各 ≤400 字），格式：`［引用 X 的话］…［它前后的对话］…`。
- 主聊天里的引用存在用户消息的 `data.quote`，模型读历史时也看得到。

## API
GET /api/bots · POST /api/bots/convs · GET|PATCH|DELETE /api/bots/convs/{id} · POST …/send · …/stop · POST|DELETE …/takeover
